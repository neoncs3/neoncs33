# NeonCS — CloudStream Türkçe Eklenti Deposu

NeonCS, CloudStream için Türkçe içerik sağlayıcılarını bir araya getiren eklenti deposudur.

## Kurulum

CloudStream uygulamasındaki depo ekleme alanına şu adresi ekleyin:

`https://raw.githubusercontent.com/neoncs3/neoncs33/master/repo.json`

Derlenmiş eklentiler [builds dalında](https://github.com/neoncs3/neoncs33/tree/builds) yayımlanır. Güncel paket listesi: [plugins.json](https://raw.githubusercontent.com/neoncs3/neoncs33/builds/plugins.json).
